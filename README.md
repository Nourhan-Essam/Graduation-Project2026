# 🥗 Wellness & Power - Graduation Project 🎓

**Wellness & Power** is a comprehensive web platform designed to solve common health issues faced by tech professionals and students who spend 12-14 hours sitting daily. It bridges the gap between Business Information Systems (BIS) and modern Web Development.

## 🤯 The Problem & Solution
Long sitting hours lead to physical pain, obesity, and eye strain. This project makes fitness a lifestyle by providing everything a beginner needs—from nutrition and guides to equipment—all in one place.

## Live Demo: (https://nourhan-essam.github.io/Graduation-Project2026/)

## 🚀 Key Features

### 🛒 E-commerce Hub
* **Dynamic Shopping**: Browse and purchase supplements, accessories, apparel, and gym equipment.
* **Smart Logic**: Real-time cart management using Local Storage.

### 🍎 Nutrition & Diet System
* **Goal-Based Filters**: Filter meals by Keto, Protein Build, Vegan, and more.
* **Calorie Tracking**: Every meal includes a detailed breakdown of calories, proteins, and carbs.

### 🏋️ Training Guides
* **Step-by-Step Plans**: Dedicated guides for Home, Gym Pro, and Yoga.
* **Multimedia Support**: Detailed instructions (PDFs) and video tutorials for injury-free workouts.

### 💳 Interactive Checkout (The Masterpiece)
* **Real-time Card Rendering**: A highly interactive UI where user data appears on a virtual card as they type.
* **Instant Validation**: Real-time error handling for a smooth payment experience.

### 📊 Admin & Coach Dashboard
* **Data Analytics**: A specialized dashboard for owners to track membership types and gender demographics.
* **Financial Analysis**: Built-in tools for business performance tracking.

## 🛠️ Tech Stack
* **Frontend**: Vanilla JavaScript, CSS3, HTML5.
* **Logic**: Advanced JavaScript internals (Event Loop, DOM Manipulation).
* **Tools**: Git/GitHub for version control.
